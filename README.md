# 島嶼茶室｜飲料購物車

島嶼茶室是以 HTML、CSS 和原生 JavaScript 製作的前端購物車練習。使用者可以從六種飲料中選購、調整杯數並查看折扣後金額，最後透過模擬結帳確認訂單。

## 使用方式

- GitHub Pages：[fiona920317.github.io/20261119-tea-cart](https://fiona920317.github.io/20261119-tea-cart/)
- 本機預覽：用瀏覽器開啟專案根目錄的 `index.html`。

1. 在飲料菜單選擇「加入」，再用購物車內的「＋」和「−」調整杯數。
2. 商品總金額達 NT$200 時自動折抵 NT$20。可加入 4 杯珍珠鮮奶茶試算，折扣前為 NT$260，應付 NT$240。
3. 點選「結帳」並確認，查看模擬訂單明細。也可點選「清空購物車」並確認，移除所有商品。

## 功能特色

- 六種飲料，同款飲料合併計算，數量減到零時自動移除。
- 即時更新品項小計、總杯數、折抵金額與應付金額。
- 支援清空與結帳確認，結帳後顯示訂單明細。
- 使用 `localStorage` 保存購物車，重新整理後還原品項與杯數。
- 響應式排版。手機版提供購物車捷徑、商品種類徽章與回到頂部按鈕。
